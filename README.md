# Embedded C Practice

A structured collection of Embedded C programming exercises, practical examples and firmware-oriented concepts designed to strengthen low-level programming fundamentals.

## Objectives

- Strengthen Embedded C programming fundamentals
- Understand pointers and memory management
- Develop proficiency in bit manipulation
- Explore memory layout and storage classes
- Understand `volatile` and `const` in embedded applications
- Practice peripheral-register-style programming
- Implement reusable embedded software utilities
- Develop coding, debugging and testing habits

## Topics Covered

| Module | Topics |
|---|---|
| Basics | Data types, operators, control statements |
| Pointers | Pointer fundamentals, arithmetic, function pointers |
| Bit Manipulation | Bit set, clear, toggle, masks |
| Memory | Stack, heap, static storage, memory layout |
| Volatile & Const | Qualifiers and embedded usage |
| Structures & Unions | Structures, unions, padding, alignment |
| Embedded Concepts | Register simulation, circular buffers, state machines |
| Examples | Practical firmware-oriented mini-projects |
| Tests | Validation, test cases and expected results |

## Compilation

Example compilation using GCC:

```bash
gcc -Wall -Wextra -Werror -std=c11 program.c -o program
```

Execute:

```bash
./program
```
